about=Part of the WFG (WorkFieldGIS) family. Builds on the built-in QGIS DWG/DXF import (Project > Import/Export > Import Layers from DWG/DXF), which stores one table per geometry type and shows CAD layers only as filters. WFG DWG Layers+ reads the same GeoPackage and builds a layer tree in which every CAD layer is a separate QGIS layer named "<cad_layer>_hatch", "_line", "_pline", "_point", "_text", "_insert", arranged in four groups by geometry type. Optionally it materializes layers into separate GPKG tables and assembles blocks (INSERT) into single multi-part features, with recursion over nested blocks, MINSERT expansion and layer 0 inheritance. Extra tools: block attributes (ATTRIB, not read by the built-in import), repair of double-encoded accented characters, recovery of layer assignment lost for heavy POLYLINE, splitting a layer by colour, pen weight or entity type. DXF needs no extra software; DWG uses the built-in QGIS import, and the optional own GDAL import of DWG needs ODA File Converter or LibreDWG (dwg2dxf) installed separately. The interface follows the QGIS language: Polish in Polish QGIS, English otherwise.
about[pl]=Wtyczka z rodziny WFG (WorkFieldGIS). Nadbudowuje wbudowany import DWG/DXF w QGIS (Projekt > Importuj/Eksportuj > Importuj warstwy z DWG/DXF), który zapisuje jedną tabelę na typ geometrii i pokazuje warstwy CAD tylko jako filtry. WFG DWG Layers+ czyta ten sam GeoPackage i buduje drzewo warstw, w którym każda warstwa CAD jest osobną warstwą QGIS o nazwie „<warstwa_CAD>_hatch”, „_line”, „_pline”, „_point”, „_text”, „_insert”, ułożoną w cztery grupy wg typu geometrii. Opcjonalnie materializuje warstwy do osobnych tabel GPKG i składa bloki (INSERT) w pojedyncze obiekty wieloczęściowe, z rekurencją po blokach zagnieżdżonych, rozwinięciem MINSERT i dziedziczeniem warstwy 0. Dodatkowe narzędzia: atrybuty bloków (ATTRIB, których wbudowany import nie czyta), naprawa podwójnego kodowania polskich znaków, odzyskanie przypisania warstw zgubionego dla ciężkiej POLYLINE, podział warstwy wg koloru, grubości pisaka lub typu encji. DXF nie wymaga dodatkowego oprogramowania; DWG obsługuje wbudowany import QGIS, a opcjonalny własny import DWG przez GDAL wymaga osobno zainstalowanego ODA File Converter albo LibreDWG (dwg2dxf). Interfejs w języku QGIS: po polsku w polskim QGIS, w pozostałych po angielsku.
